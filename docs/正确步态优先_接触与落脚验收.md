## 为什么不能只看前腿站宽

PPO495在标称平地12秒回放中：平均前足站宽约38.2cm，后足约17.8cm。接触时序接近对角交替，但按本项目初始落点范围，FL/RL/RR落点都存在偏离。因此“接触模式合格”和“前腿变窄”都不足以代表四足步态正常。首次测量和足印图：`outputs/20261107_front_leg_diagnosis/normal_gait_baseline.json/.png`，该首次报告使用足端中心速度作支撑移动指标；正式审计改用平地球形足底接触点速度近似，避免将刚性足滚动全部算为滑移。

28.4cm是本MJCF默认姿态的站宽参考，前后髋中心约±0.1934m。下面范围是本项目低速直行的工程约束，不是通用生物力学标准；必须结合视频复核，不能把矩形窗口机械套到楼梯或转弯落脚上。

## 训练约束

复用原自写PPO和176维视觉融合网络，12关节接口、PD与动作scale不变。视觉与本体历史/速度估计初期冻结，小学习率2e-6调整控制分支，每50次更新评估。姿态成本逐步增加，不直接裁剪髋关节目标。

- 保留对角接触、支撑、连续腾空、抬脚、滑移等原奖励。
- 对四个髋关节过度外展/内收加入软惩罚，前腿站宽额外约束。
- 在平地直行/站立，对支撑足横向偏离与落地瞬间落点偏离加入软惩罚，不指定摆动轨迹或强迫恒定两足支撑。
- 楼梯、碎石和明显转向不套用平地落点矩形；保留适应高差所需活动余量。

## 数值准入门槛

每轮用独立确定性平地回放检查四脚，另测3cm/20cm完整路线。固定速度阶段不运行33项变速停车，也不伪造其通过率；它们留待后续域随机化任务。

| 类别 | 初始工程门槛 |
| --- | --- |
| 接触步态 | 原对角组合/支撑/抬脚频率/机身波动门槛全部通过；允许三、四足过渡支撑 |
| 连续腾空 | 全路线及平地最长≤0.06秒，腾空比例≤1% |
| 站宽 | 前后足平均分别24.4～32.4cm，P95分别≤34.4cm |
| 髋关节姿态 | 四髋绝对角P95各≤0.25rad |
| 平地落点 | 每脚相对默认参考，前后±16cm、横向±4cm内的落点≥95%，逐脚统计 |
| 落脚事件 | 接触由无到有且摆动至少0.08秒，每脚至少4次/seed，避免把站住或接触抖动当成行走 |
| 交叉落脚 | 脚跨到机体另一侧的样本比例≤0.1% |
| 支撑期 | 每脚支撑占比0.3～0.8，足底接触点估计切向速度P95≤0.15m/s |
| 完整路线 | 六档固定120/120、独立120/120，速度RMSE≤0.1m/s、原步态及数值门槛通过 |

球形足底速度是按平地法向与刚体速度计算的近似，不冒充接触求解器直接测得的真实滑移。复杂地形落脚不强制采用平地矩形，需结合完整路线接触数据与视频确认。

## 可复核证据与域随机化准入

`scripts/audit_normal_gait.py`保存逐脚指标、落地事件CSV、50Hz接触曲线CSV及足印图。完整验证通过后自动生成3cm和20cm完整视频，视频配套CSV追加四脚机体系xyz坐标及接触状态。

数值通过后进入`nominal_gait_passed_needs_visual_review`，相机与动力学随机化仍关闭。生成的`gait_review.template.json`默认approved=false；只有实际查看接触时序、落脚位置和视频后，复核者才填写`gait_review.json`。要求批准标志为布尔true、同一权重SHA256、接触与落脚均已复核、视频列表匹配且文件存在。不得为了推进流程先填通过。

这里是对训练产物的实际复核，不是向用户额外索要运行许可。没有复核记录或仍有外八字、交叉落脚、拖脚、滑移时，不能打开域随机化。

复核通过后从正常步态权重接续25%→50%→75%→100%随机化，并使用该正常策略作冻结参考。后续每批仍保留四脚接触/落点检查，防止随机化重新引入异常步态；完整变速停车与相机边界测试恢复。学生参考相机按其checkpoint配置加载，避免将新D435i策略误接旧相机内参。
