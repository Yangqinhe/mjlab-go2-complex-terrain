## 数值准入门槛

每轮用独立确定性平地回放检查四脚，另测3cm/20cm完整路线。固定速度阶段不运行33项变速停车，也不伪造其通过率；它们留待后续域随机化任务。

| 类别 | 初始工程门槛 |
| --- | --- |
| 接触步态 | 原对角组合/支撑/抬脚频率/机身波动门槛全部通过；允许三、四足过渡支撑 |
| 连续腾空 | 全路线及平地最长≤0.06秒，腾空比例≤1% |
| 站宽 | 前后足平均分别24.4～32.4cm，P95分别≤34.4cm |
| 髋关节姿态 | 四髋绝对角P95各≤0.25rad |
| 平地落点 | 每脚相对默认参考，前后±16cm、横向±4cm内的落点≥95%，逐脚统计 |
| 落脚事件 | 接触由无到有且摆动至少0.08秒，每脚至少4次/seed，避免把站住或接触抖动当成行走 |

球形足底速度是按平地法向与刚体速度计算的近似，不冒充接触求解器直接测得的真实滑移。复杂地形落脚不强制采用平地矩形，需结合完整路线接触数据与视频确认。
