## 路线纠偏

固定机体系前进速度仍为`vx=0.3m/s`、`vy=0`。增加高层路线指令生成器，将横向偏差与航向误差转为已有的`wz`命令：

```text
desired_yaw = atan2(-0.7 * lateral_error, 1)
yaw_error = wrap_to_pi(desired_yaw - body_yaw)
wz_command = clip(2 * yaw_error, -0.5, 0.5)
```

路线沿世界X方向，横向偏差相对当前路线中心线计算。参数集中在`RouteCommandConfig`，纯函数位于`env/commands.py`。旧checkpoint缺少该配置时默认关闭，新训练显式启用。策略仍读取原45维本体及历史，3维命令中的wz现在随偏差变化；176维融合、12关节输出、PD和关节/力矩限幅保持当前实现。

训练增加横向偏差平方惩罚（-1）及转向速度误差平方惩罚（-0.8），只在路线模式启用。依然以完整走过全部区域并到达终点判成功，路线宽3m、机体横向越界阈值±1.3m，验收阈值仍为成功率≥80%及vx RMSE≤0.1m/s。

该高层指令生成器需要相对路线的横向位置与航向，仿真由机器人状态提供；实际部署需对应里程计/定位。它不将位置或航向直接追加到actor输入，也不使用相机帧状态特征。
