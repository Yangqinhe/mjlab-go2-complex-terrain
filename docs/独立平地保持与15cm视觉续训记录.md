# 独立平地保持与15cm视觉续训记录

## 当前起点及限制

选用 `outputs/20261108_044747_525028_reference_control_distill_seed89996/checkpoints/iteration_50.pt` 作为微调起点。这是动作监督第50次更新，对应PPO1595、视觉300，不能称作PPO第50批。

该候选通过正常平地seed56200，实际深度15cm为13/20、速度误差0.1023999m/s、最长腾空0.22s。换用教师高度特征后19/20、0.0778880m/s、最长0.20s，是特权诊断而不是学生验收。视觉感知与下楼接触均有改善空间。

用户接受完整路线速度误差上限0.10340770147740841m/s、连续腾空上限0.08s。其余落点、站宽、支撑期滑移和接触门槛不变。域随机化关闭。最终还需六档固定120及fresh120路线、独立平地三个seed、同一最终权重的平地与20cm视频复核。

## 本阶段方法

使用独立入口 `scripts/distill_visual_terrain.py`。冻结本体历史、速度估计、动作MLP、log_std及critic，只训练视觉CNN/GRU，网络结构和部署输入输出保持不变。

复杂地形标签来自冻结教师62001的高度编码，经10Hz采图/reset时序保持。冻结的当前学生控制网络接收该特征生成监督动作，避免复用旧教师控制网络造成动作含义不匹配。路线中的平地区域和额外20m平地任务使用冻结起点学生自身的视觉特征作为标签，保持已经正确的平地控制行为。

64路线+64独立平地。路线档位0/6/9/12，对应3/9/12/15cm，几何seed56000。训练seed89998；固定vx0.3、vy0、wz0。每批采125个控制步，其中前25步作为GRU上下文，不计损失；视觉更新20步，按16世界一组BPTT。损失为动作MSE加0.1倍特征MSE，平地样本权重5，学习率2e-5。采样动作由0.5引导与0.5学生混合，评估完全使用学生。

独立任务的图像帧库合并时修正帧索引，保持各世界reset掩码和GRU初始状态。仅恢复本算法自己的视觉优化器，跨动作监督/PPO阶段重新创建视觉优化器。PPO、视觉、动作监督计数分别存储；非有限损失或仿真数值异常停止本批并保留记录。

## 检查与后续

GPU检查使用8路线+4平地、4次更新，临时检查源仅将回合长度改为8秒，以覆盖重置；正式训练恢复原回合长度。复杂地形与重置均出现，无数值异常，只有16个视觉张量改变，其他actor张量和critic不变，检查权重不参与选优。证据位于 `outputs/nominal_gait_goal_audits/visual_joint_flat_smoke_verification.json`。

正式100次更新结束后评估25/50/75/100不可变检查点。每个先检查正常平地56200，通过后评估15cm五seed×四布局。完成率、速度、接触、落点和数值条件共同决定是否通过。特权诊断与引导训练完成率不计入验收。

工作任务状态为 `outputs/nominal_gait_goal_audits/visual_joint_flat/status.json`，统一入口为 `outputs/active_student_training.json`。本阶段不自动开启域随机化，不自动发布student_final.pt。视觉候选通过后仍须继续解决下楼接触，开展PPO微调及完整验收。
