## 新训练目标与实现

固定vx=0.3m/s，以对角腿交替支撑、平地无明显腾空的小步行走为目标；同时允许正常的三足、四足支撑过渡。当前任务没有鸿沟，不将持续腾空或前后腿成组跳跃作为平地行走方式。

从随机初始化的新教师开始，不加载原跳跃策略。仍为45维本体、10步历史、176维融合、12关节位置偏移及原PD控制；不增加相位输入。新参数集中在`env/config.py:GaitConfig`，接触统计和奖励位于`env/gait.py`，通过可选配置保留旧checkpoint加载能力。

- 用5N竖直接触力判断支撑；记录每只脚的腾空时长、重新触地、支撑组合及机身起伏。
- 惩罚四脚同时离地；在平坦区域额外惩罚单足支撑、前后/同侧两足组合、垂向速度和高度起伏。
- 平地两足支撑时奖励对角组合。以触地事件奖励适当摆动，惩罚极短摆动，避免碎步或原地站立冒充步态。
- 平坦区取平地、平台、过渡和终点内部，避开边缘0.35m；统计排除reset后0.5秒落地过程。上台阶不强制平地的双足支撑节律，但仍惩罚全身腾空。

这些奖励不能单独证明动作正确。评估和最终发布同时增加平地步态门槛：

| 指标 | 当前门槛 |
|---|---|
| 平地腾空采样占比 | ≤1% |
| 最长连续腾空 | ≤0.04s |
| 平均支撑足数 | ≥1.9 |
| 两足支撑中的非对角组合占比 | ≤10% |
| 垂向速度RMS | ≤0.15m/s |
| 相对地面机身高度标准差 | ≤0.025m |
| 每只脚有效重新触地频率 | 0.35～3Hz，摆动至少0.08s |

同时保留完整路线成功率≥80%、vx RMSE≤0.1m/s，旧结果不豁免新步态要求。统计通过后仍须检查视频，确认不是拖脚、原地抖动或异常姿态；不只凭一个reward或接触率宣称步态正确。

后续选模在通过档数相同时优先减少归一化步态违规，再比较成功率和速度误差，避免回退到速度更准但跳跃的策略。发布入口要求新步态配置启用且每个高度均满足步态门槛。

## 实际训练与验证

新平地训练目录为`outputs/20261105_150121_pipeline/`，2048环境，每100次更新评估20个独立seed/布局组合；未通过继续训练，每25次更新保存权重。当前仅进行平地阶段，通过后输出`flat_ready`，再录像检查，随后恢复低障碍和9/12/15/18/20cm课程、视觉蒸馏及学生PPO。最终仍对所有高度做新种子复核，不缩减复杂地形目标。

```bash
./run.sh python -m scripts.train_pipeline \
  --walking-gait --flat-only --teacher-iterations 100 \
  --teacher-rounds 0 --student-rounds 0 --actor-lr 0.0001 \
  --horizon 64 --batch-size 8192 --save-interval 25 \
  --adaptive-lr --kl-stop-multiplier 2 --route-following
```

已有验证：对角交替样例通过，成组跳、腾空、站立和碎步样例均被门槛拒绝；4环境真实PPO、GAE、超时bootstrap、局部reset和数值异常终止检查通过。尚未证明新机器人策略已经学会目标步态，必须以实际训练、接触数据和录像为准。
