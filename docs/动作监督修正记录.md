# 动作监督修正记录

日期：2026-11-06。目标仍是固定vx=0.3、最高20cm复杂地形的视觉学生，网络保持176维融合和12关节输出。以下实验均需完整路线/步态验收，不按监督MSE判定训练成功。

## 动作头单独适配

从`20261106_091513_383321_student_ppo_seed92025/checkpoints/final.pt`出发，固定视觉、本体历史和速度估计，用冻结教师2000轮的动作均值作标签，只训练动作MLP。学生自主控制，叠加0.01动作探索；教师不参与执行。视觉LR=0、公共LR=1e-6、warmup=0、latent系数0、历史/速度冻结，256环境，新地形seed63020，共50次有序监督迭代。

新增默认False的蒸馏`--freeze-proprio`；visual_lr=0时真正冻结CNN/GRU，避免建立无用反向图。参数/网络接口保持，初始本体基线标记仍禁止进入视觉蒸馏。实际4环境一次更新检查确认仅动作MLP改变、视觉/历史/速度/critic/log_std均逐项不变、数值有限，记录`20261106_095126_358499_distill_seed69000/head_only_verification.json`。

正式50次后仍确认冻结模块及critic/log_std不变，随后做25次真实PPO：256环境、H128/B16384、LR=1e-8、std=0.02、冻结感知，原基础腾空-2及长腾空-20，非平地重叠系数0。最高20cm完整20案例仅5/20完成、vx RMSE=0.13006，正式拒绝；没有使用预留34000～34004，也没有准备/发布成功权重。完整目录`outputs/20261106_095743_head_refinement`，模型`20261106_100204_153135_student_ppo_seed93000/checkpoints/final.pt`。

此结果表明固定当前视觉特征后，单独拟合动作头未解决任务；不能因MSE有限或参数只改一小部分就认定安全。

## 联合视觉与动作头适配

下一实验仍从原PPO100出发，固定本体历史与速度估计，同时训练视觉CNN/GRU和动作MLP。纯学生执行、教师只给动作标签，不使用特征GT对齐损失，减少固定视觉表示和动作映射之间的约束。视觉LR=1e-5、公共LR=1e-6、latent系数0，新地形63021、50次有序监督，随后同样25次LR=1e-8 PPO与六档/新seed完整验收。当前目录`outputs/20261106_101628_joint_refinement`正在执行，正式效果待结果。

可复现联合监督阶段：

```bash
./run.sh python -m scripts.distill_student \
  --teacher outputs/20261105_212457_360463_teacher_seed62001/checkpoints/final.pt \
  --resume outputs/20261106_091513_383321_student_ppo_seed92025/checkpoints/final.pt \
  --num-envs 256 --iterations 50 --seed 69002 --terrain-seed 63021 \
  --warmup 0 --visual-lr .00001 --common-lr .000001 --latent-coef 0 \
  --teacher-mix 0 --action-noise-std .01 --freeze-proprio \
  --training-levels 0 6 9 12 15 17 17 17 17 17
```

训练和最高档优先的完整验收按顺序使用本项目GPU，另一路落足重叠PPO的当前子任务结束后等待，实验结束自动继续。所有源权重、失败报告、监督权重及训练输出保留。
