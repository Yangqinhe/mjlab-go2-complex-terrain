# 均值闭环监督修正实验

本实验检查固定地形上“PPO随机采样表现较好、均值推理仍失败”的现象，不替代最终步态验收。原 PPO 训练独立继续，域随机化保持关闭。

`scripts/refine_student_mean.py` 只更新动作 MLP。采样时始终执行学生自己的均值动作；平地动作标签来自正常步态参考945，复杂地形来自冻结195及其原深度相机。不直接执行专家动作，不增加学生观测。视觉、历史编码、速度估计、标准差和critic均冻结。监督损失为12关节均值动作的MSE。

参数由CLI集中管理，复用现有环境、模型和检查点工具。保存为`mean_bc`阶段，PPO迭代数不变，监督更新和新增采样数另记。此阶段优化器仅含动作MLP，因此不写`task_configs`，恢复现有多任务PPO时使用新的优化器。

## 实际检查

- 12环境、4次更新冒烟：数值异常0，只有动作MLP六个张量改变；其余网络和critic逐一核对不变。旧195检查点没有camera字段，已沿用现有加载器的默认相机方式处理，再运行通过。
- 96环境（64路线+32平地）、200次监督更新，额外采样614400步，PPO迭代仍1320。训练完成、数值异常0。
- 正常平地结果如下，三者均未通过，未进行后续路线验收，也未替换主训练权重。

| 监督更新 | 前/后平均站宽（m） | 结论 |
|---|---|---|
| 50 | 0.349 / 0.229 | 站宽、支撑速度不合格 |
| 100 | 0.340 / 0.237 | 站宽、支撑速度不合格 |
| 200 | 0.338 / 0.245 | 站宽、支撑速度不合格 |

直接动作回归未保住当前正常平地步态；不能凭动作MSE下降认定策略更好，也不能仅据本实验确定唯一原因。后续仍按原PPO奖励及完整验收进行训练。复现该脚本应作为独立候选实验，禁止直接当作最终权重发布。

## 后续参考判定修正

上述已拒绝的200次BC实验使用旧参考选择版本：取反统计平地掩码会在每次reset前0.5秒错误选择地形专家。实验目录内的 `source_refine_student_mean.py` 保留该版本，历史结果不变。

当前脚本改用不依赖回合年龄的纯几何判定，并记录 `reference_target_revision=geometry_v2`；尚未重跑完整BC实验，不能将旧失败结果解释为修正后效果，也不能凭修正推断BC已可用。主线继续PPO，不采用该BC权重。
