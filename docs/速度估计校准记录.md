# 速度估计校准记录

## 目的与边界

视觉学生在部分下楼梯回合出现60～80毫秒腾空。检查现有速度估计头是否影响落足时序，保持176维融合、深度图、控制频率、动作输出和验收标准不变。真实速度只用于离线诊断或训练标签；交付策略推理始终使用历史本体观测估计速度。

## 真实速度替换诊断

来源：`outputs/20261106_105709_velocity_diagnostic/report.json`。使用联合适配后PPO50学生，在9cm、seed10000、4种布局进行完整路线重放。正常估计模式4例成功，其中一例腾空0.06秒；临时用仿真真实速度替换3维速度特征后，4例成功且最长腾空均不超过0.04秒。原估计误差各轴约0.1m/s。

这是4例诊断，不能代替20例正式验收，也不能将真实速度作为部署输入。

## 校准实现

入口：`scripts/calibrate_velocity.py`。固定历史编码器、视觉CNN/GRU、动作MLP、探索标准差和critic，只更新原有velocity_head。采集学生自身闭环状态，以机体系真实速度为监督标签；跳过reset后0.5秒的初始化数据。校准期间动作也使用估计值。无新增第三方依赖，不改变核心PPO接口。

保留真实PPO轮数和步数，额外校准单独记录。清空actor旧优化器动量，避免续训沿用已失配的动量。`metrics.csv`保留来源PPO曲线，校准误差单独保存在`velocity_metrics.csv`；来源PPO配置保存在`ppo_source_config.json`。

## 实测与拒绝原因

- 4环境、2次校准实际运行通过；逐参数确认只有速度估计头变化，critic和PPO计数未变，权重有限。
- 校准权重继续实际PPO一次更新通过，见`outputs/20261106_111810_804871_student_ppo_seed70001/`；这只是格式与续训兼容检查。
- 正式256环境、20次校准完成，见`outputs/20261106_112901_441334_velocity_calibration_seed70002/`。每次采样128步、5个监督epoch、学习率1e-4，数值异常0。
- 正式校准权重在20cm完整20例验收中成功率0、vx RMSE=0.18673，因此拒绝，未使用36000新seed，也未生成成功交付。审计目录：`outputs/20261106_113019_checkpoint_audit/`。

监督误差降低不能证明闭环步态变好。原策略可能适应了原估计器的偏差；直接改变估计映射会改变动作。下一步只筛查2.5%、5%、10%、20%的参数校正幅度。小样本筛查只决定是否值得完整验收；最终仍须六档各20例选择、全新seed复核、录像检查和最终权重容量复测。
