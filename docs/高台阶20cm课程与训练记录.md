# 单级20cm楼梯：课程扩展与实际训练记录

> 2026-11-02更新：下述旧流水线在第2400轮未通过基础档后停止。现已使用调整后的PPO配置重新续训，当前目录`outputs/20261102_213452_pipeline/`，见[PPO续训与对照记录](PPO续训与对照记录.md)。20cm课程与分高度验收目标保持不变。

用户要求继续训练，后期楼梯最高约20cm。当前按**单级踏步高度20cm**处理：4级上楼梯累计高0.8m，踏面深0.35m，接平台和下楼梯，再经过静态碎石。该目标已经写入训练课程，但不表示机器人已通过20cm。

## 训练安排

当前从已有复杂地形教师继续，保持机体系速度指令`[0.3,0,0]`。自写PPO、45维本体、双帧48×64深度、CNN/GRU、176维融合及12关节输出不变；域随机化仍关闭。

| 阶段 | 单级高度范围 | 高度档数×布局 | action_scale |
|---|---|---|---|
| 基础复杂地形 | 3–9cm | 8×4 | 0.5rad |
| 扩展一 | 3–12cm | 10×4 | 0.6rad |
| 扩展二 | 3–15cm | 13×4 | 0.7rad |
| 扩展三 | 3–18cm | 16×4 | 0.8rad |
| 目标档 | 3–20cm | 18×4 | 0.9rad |

阶段参数集中在`rl/config.py:STAIR_STAGES`，流水线将其写入每次运行的`curriculum.json`。每档最多3轮、每轮500次PPO更新；未达标保存失败报告并停止升档，不能用“训练运行完”代替“能力通过”。教师2048环境，视觉阶段默认256环境。

每档教师同时评估3cm与该档最高台阶，分别使用20个独立seed/布局组合、完整回合、Gaussian均值动作。两组都满足成功率≥80%、vx RMSE≤0.1m/s才升档。完成目标档后再蒸馏视觉学生；最终学生分别评估3/9/12/15/18/20cm，全部达到相同门槛才允许发布最终权重。基础档通过不能写成20cm通过。

## 动作范围、观测和奖励调整

动作保持12维原始Gaussian采样，执行前截断[-1,1]，关节目标为：

```text
q_target = clip(q_home + action_scale * a_exec, joint_lower, joint_upper)
```

后期逐档扩大偏移范围，始终保留原关节硬限位、PD增益40/2和23.7/45.43N·m力矩限幅。推理必须从checkpoint读取该档环境配置，不能拿0.9尺度的策略固定用0.5执行。网络结构及参数量不变。

运动学采样使用本地Go2模型，固定机身水平、基座z=0.27m、前腿hip=0，每档对thigh/calf各采81点，并遵守关节限位。测得前足足底最大z如下：

| action_scale | 最大足底z |
|---|---|
| 0.5 | 0.1188m |
| 0.6 | 0.1503m |
| 0.7 | 0.1797m |
| 0.8 | 0.2055m |
| 0.9 | 0.2267m |

这只是单腿静态可达空间，不证明动态上阶、支撑稳定或通过率。原0.5范围在此姿态下抬脚空间有限，因此采用渐进尺度，不直接将现有策略的物理动作放大到0.9。一次直接放大范围的小批量程序检查曾出现跌倒，该权重只作接口检查，不参与正式训练续接。

教师187点高度扫描保持除以0.5的缩放；15cm及以上阶段将归一化截断从±1扩到±2，使0.8m平台不被统一截成0.5m。该变化只涉及教师/critic的特权高度，学生仍仅输入深度与本体，不增加age/valid特征。

针对失败录像中抬脚不足，增加一项足端间隙惩罚：查询足端前方0.2m地形，目标足底间隙为`0.03m + max(前方高度-足下高度,0)`，惩罚移动足的间隙误差平方，按水平足速平方根加权，系数-5。静止支撑足速度近零，不指定walk/trot相位。参数集中在`TrainingRewardConfig`，日志增加`reward_foot_clearance`。

检查训练奖励时发现地图边缘高度异常：足端越过分配地块的边缘后，原查询返回-10m，实际相邻地块仍存在碰撞体，可能产生错误的支撑高度惩罚。现优先查本块，缺失点再分块查询最终模型全部地形盒；真正离开整张地图时，支撑高度不使用-10哨兵。CPU射线对照已验证相邻地块，未修改模型或第三方源码。

## 续训和归档

修复`--resume`时显式`--levels/--layouts`被旧配置覆盖的问题。新checkpoint可保存各环境地形等级；续训按**实际单级高度**映射到新档位，环境数变化时抽取对应难度分布，不把旧等级索引机械复制到新地图。旧权重没有课程状态时兼容从该档最低级开始；物理状态仍从新回合开始。

最终发布进程需检查同一学生checkpoint的全部高度报告，尤其20cm最高档；失败或缺少任何目标高度的报告都不发布“最终模型”。代码和文档上传原私有仓库，最终完整pt、部署配置、评估、曲线及成功重放仍通过Release交付。
