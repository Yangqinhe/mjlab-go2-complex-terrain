# 学生策略持续域随机化训练（2026-11-07）

## 目标与当前状态

持续训练视觉学生，恢复原195学生的复杂地形能力，同时加入连续速度、停车、负载、摩擦、动力学、D435i视角与带墙内容变化。只训练学生；195学生和原2000教师冻结作为参考，不重新训练教师。

原195在无新增随机化条件下，六档3/9/12/15/18/20cm固定120条和独立120条路线全部完成。新随机化学生尚未达到这个效果，所有中间权重均不能替代原发布权重。

## 现有失败与诊断

- 先自由速度、再单独复杂路线容易遗忘；此前自由任务最好25/33，复杂地形阶段20cm仍0/8。
- 2026-11-07原相机25°、关闭新增视觉扰动但保留25%强度物理随机化的隔离诊断：原195在20cm四布局4/4完成，vx RMSE 0.08008m/s，最长腾空0.06秒，数值异常0。文件：`outputs/20261106_135343_676539_student_ppo_seed92037/evaluations/eval_20261107_022825_093826.json`。这是弱物理扰动单seed诊断，不能代替完整随机化验收。
- 同状态旧相机一致性、特权教师顺序蒸馏都产生过很低的动作监督损失，但新相机闭环高台阶仍失败。教师采样完成率和监督损失不作为学生能力证明。
- 早期联合训练的选择分数对步态约束不够强；后续增加步态违规扣分，并固定评估随机化seed，避免训练批次改变测试条件。

## 联合PPO

默认384个路线环境、128个自由速度环境，总512。该设置为了给双任务、冻结参考模型和视觉采样留显存，不是2048容量上限结论。

路线始终混合六档地形、四布局；vx=0.3，vy=0，wz由原路线跟踪器产生。自由任务在宽场地连续采样vx∈[-0.3,0.3]m/s、vy=0、wz∈[-0.5,0.5]rad/s，额外含零速度、固定正向锚点和前6秒0.3后停车片段，停车保持8～14秒。并非训练倒走20cm楼梯或直角转弯导航。

每轮100次PPO更新，H=128，mini-batch8192，最多5epoch，actor LR初值5e-6、critic LR3e-4。基础标准差0.04；路线乘0.5，自由任务乘2。实际概率、old/new log-prob和KL均使用乘后的标准差，不能只改采样而沿用旧概率。评估确定性使用均值动作。

Actor仍为45维本体+10步历史+双帧48×64深度，融合176维后输出12维。Actor不接收任务标签或地形真值。Critic原最后一维路线进度，在自由任务标为-1；只影响训练价值估计。

路线参考为冻结195同状态旧相机动作；自由任务参考为此前2050学生，对恰好正向0.3/不转弯的锚点不施加自由参考。参考MSE加入同一次PPO actor更新，服从同一KL早停，没有额外绕过早停的优化步骤。本体/速度网络初期冻结，路线恢复后再逐步放开；视觉分支在PPO固定以控制显存。

## 视觉继续学习与课程

不能永久固定视觉后只调整动作网络。连续若干轮选模无改善时，调用单独顺序BPTT更新CNN/GRU：冻结旧2000教师提供当前状态动作和地形特征监督，采样动作混合50%教师/50%学生，更新仅限学生视觉，随后以确定性学生评估并决定保留或回退。监督采样临时关闭帧传输延迟/丢帧以对齐时序，PPO和评估明确恢复该阶段完整配置。

随机化强度0.25→0.5→0.75→1；每级通过路线、速度和停车门槛才升级。相机俯角从20～30°逐步扩大到最终20～50°，名义视角同步移动；侧墙四布局始终存在。负载从0.125kg到0.5kg，质量/PD/阻尼/摩擦/噪声按强度逐步扩展；20ms动作与帧延迟从第二级加入。完整范围仍以`domain_randomization/config.py`和每次保存的task_configs.json为准。

## 评估与持续运行

同一评估seed固定物理/视觉扰动seed=200000+terrain_seed，训练seed与评估seed分离。每轮先筛查3cm、20cm各4布局，再做33项连续速度/停车测试。按共同分数选择，步态违规扣分；不能用总reward代替验收。失败候选保存，下一轮从较好的已测权重继续。
