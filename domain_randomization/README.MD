# 域随机化

2026-11-06已接入，默认关闭，旧195权重仍按原配置运行。负载、摩擦、物理建模误差及执行器参数按环境在reset采样，观测噪声每控制步缓存一次，视觉误差按采图处理。

- `config.py`：集中开关、种子和范围。
- `dynamics.py`：刚性负载质心/主惯量合成、摩擦、PD、输出上限、被动阻尼/摩擦；声明per-world字段及派生量重算。
- `runtime.py`：观测偏置/噪声、重力方向扰动、0/20ms整步动作延迟；外力脉冲已预留可选实现，首批配置为0。
- 自定义射线相机与延迟帧队列接入`env/perception/`，不修改网络输入维度。

速度指令属于任务变化，仍在`env/commands.py`管理：vx连续[-0.3,0.3]m/s、vy=0、wz连续[-0.5,0.5]rad/s，另有零指令概率及0.3到0的独立停车测试。路线纠偏和自由速度是分开的模式，不将随机wz覆盖为路线wz后仍宣称已训练随机转向。

第一批0～0.5kg负载，摩擦0.65～1.0，标称机身密度0.95～1.05倍，kp/kd各0.95～1.05倍，有效输出上限0.95～1.0倍。只对本体质量建模误差统一缩放质量/惯量，额外负载另行合成。20%环境保留标称参数。

当前不包括：完整状态通信延迟、任意毫秒动作延迟、真实负载碰撞外形、机器人自身视觉遮挡、视觉编码器端到端PPO更新。首批CNN/GRU冻结；本体历史与速度估计头解冻。相机平移/转角、深度噪声/像素缺失、少量丢帧及0/20ms图像传输延迟已启用，迟到帧配采图时本体输入GRU，维度保持176。

整体设计与本次实际范围分别见`docs/负载与变速_整体域随机化方案设计.md`和`docs/负载与变速_域随机化续训记录.md`。代码接入与短PPO检查通过不等于新任务验收通过。
